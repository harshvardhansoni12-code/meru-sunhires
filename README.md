## Surhires

A responsive recruitment platform demo with three routes:

- `/` — Home, hiring flow, featured roles, testimonials and FAQs
- `/jobs` — Job listings with working role, location and work-type filters
- `/employers` — Three pricing tiers and a validated demo job-post form

### Brand direction

The visual direction uses deep navy for trust, teal for confident action and a
warm off-white background to keep the experience welcoming and easy to read.
The interface uses CSS-made visual elements and does not depend on externally
hosted stock photography.

The plans, companies and job listings are sample content for this frontend
assignment. The employer form validates in the browser and does not transmit or
store submitted information.

### Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

### Production checks

```bash
npm run lint
npm run build
```
